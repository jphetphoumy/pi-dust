# Support

## Usage questions and bugs

Please use GitHub Issues for:

- bug reports
- feature requests
- documentation improvements
- questions about expected project behavior

## Before opening an issue

- read [`README.md`](README.md)
- check the guides in [`docs/`](docs/README.md)
- review existing open and closed issues

## Security issues

For security concerns, follow [`SECURITY.md`](SECURITY.md) instead of creating a
public issue.
